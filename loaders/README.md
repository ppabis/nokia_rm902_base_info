# loaders

Vendor loader bodies, extracted from Nokia Care Suite flash components:

- `secondary.bin` — 22,976 bytes, SHA256 `0b894fec…23cce`, from `XG223_v11_usb2nd.fg`
- `algorithm.bin` — 207,440 bytes, SHA256 `81fe1d88…ab45a`, from `XG223_v11_usbalg.fg`

Nokia published no license for these files. The only license text shipped with
Care Suite (`copyright_notices_and_licenses.chm`) covers bundled third-party
code, not Nokia's own loaders, and the installer EULA grants no redistribution.
Care Suite binaries carry `Copyright © 2014 Microsoft Mobile Oy`.
Care Suite is discontinued (last release 5.6.134.1513, 2015) and the phones it
served are out of support, so we treat the loaders as abandonware. They are here
to read hardware we own — we assume the right to repair as the owners.
